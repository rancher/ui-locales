# SUSE Localization Pack

**Adds support for additional locales to the Rancher UI.**

### Overview
The SUSE Localization Pack extends the Rancher UI with additional translated locales so teams can work in their preferred language. It improves accessibility for global operators by providing broader UI language coverage beyond the default set.

### Target Use Cases
* **Global Platform Teams**: Enable multilingual Rancher experiences across regions.
* **Enterprise Operations**: Improve usability for administrators who prefer non-English interfaces.

### Deployment Path
* **Prerequisites**: A Rancher version compatible with this extension's catalog requirements.
* **First Step**: Install the **SUSE Localization Pack** from the Extensions catalog, then select a supported locale in the Rancher UI.
